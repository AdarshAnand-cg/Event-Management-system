# Event Management System

A modern and user-friendly **Event Management System** designed to simplify the process of creating, organizing, managing, and participating in events. The platform provides a centralized solution for event organizers and attendees to manage everything efficiently.

##  Overview

The **Event Management System** helps streamline the complete event lifecycle — from event creation and registration to schedule management and attendee tracking.

It is designed with a clean and intuitive interface to provide a smooth experience for both **event organizers** and **attendees**.

##  Features

* **Event Creation** – Create and manage events with essential details.
* **Event Registration** – Allow users to register for upcoming events.
* **Event Management** – Update, organize, and manage event information.
* **Schedule Management** – Manage event dates, timings, and schedules.
* **Attendee Management** – Track registered participants efficiently.
* **Event Discovery** – Browse and explore available events.
* **User-Friendly Interface** – Simple and intuitive design for better usability.
* **Responsive Design** – Designed to work smoothly across different screen sizes.

##  Objectives

The main goal of this project is to create a centralized platform that makes event management **simple, organized, and efficient**.

It aims to reduce manual work for organizers while providing attendees with an easy way to discover and register for events.




##  UI/UX Design

The interface is designed in **Figma** with a focus on:

* Clean and modern layouts
* Easy navigation
* Consistent typography and spacing
* Intuitive user interactions
* Accessible information hierarchy
* Responsive design principles
